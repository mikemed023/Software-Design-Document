# Software-Design-Document
Software design document for the development of the Draw it or lose it game app

Briefly summarize The Gaming Room client and their software requirements. Who was the client? What type of software did they want you to design?

The Gaming Room client wants to make their popular game Draw It or Lose it, available to more users. For this reason they have ask Creative Technology Solutions to develop a web-based version of the game that is capable of running on multiple platforms. The software must be able to display high definition images to users from different platforms in a fast and efficient way.

What did you do particularly well in developing this documentation?

In the development of this document I did particularly well on the evaluation and recommendation sections. On the evaluation part, I was able to provide the client with the advantages and disadvantages as well as the requirements of several operating systems.  On the recommendation section, I provided the client with what I believe is the best way to design and develop their gaming app. 

What about the process of working through a design document did you find helpful when developing the code?

Working through the domain model section of the design document help me visualize the structure of the code better. Seeing all the classes, their attributes, and how they relate to each other made it easier to write the code necessary to make the app work.

If you could choose one part of your work on these documents to revise, what would you pick? How would you improve it?

One part that I could improve is the Designs constraints. When I wrote this part I didn't have a clear picture of how the app would work and what all the requirements were. After learning about the whole development proccess more designs constraints came up that I didn't think of before such as memory or storage management, and choosing between a traditional operating platform or opting for a cloud-based one.

How did you interpret the user’s needs and implement them into your software design? Why is it so important to consider the user’s needs when designing?

The knowledge I gained from the provided resources each weak, help me see the user's needs more clearly. Using the user's needs as a guide, I was able to choose the best components to develop the app. As with any product that is made for the consumer, the game app must be designed and built with the user in mind in order to maximize the success of the app once it is launch in the market.

How did you approach designing software? What techniques or strategies would you use in the future to analyze and design a similar software application?
I approached the designing part of the software with an opened mind. I set aside my preferences, and analyzed all the available options. In the design of future software, taking enough time to do research, and communincating with the client will be very important. Getting educated about how the different operating systems work and what do they have to offer, as well as getting familiar with different design architectures, will help me make the choice that is best suited for  the client's needs.
